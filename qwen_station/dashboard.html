What a client needs

Model

How the model starts. The preset, with the context size, is in the header of the window.

7 is what the drafter was trained for. More makes reasoning faster; each extra token costs about 5,400 tokens of context.

The slots share the context. A slot costs nothing; every request that runs takes about 52,000 tokens of the context for its own state, plus its text. A request that does not fit waits.

0 is off. A large session that another one pushed out of the GPU then comes back from RAM in about a second instead of being read again, which takes up to half a minute. About 3.5 GiB per 100,000 tokens. The RAM is taken when the model starts.

The model reads images in requests, up to 4 per request. The image encoder needs up to 1.7 GiB of VRAM, so the context gets one or two steps of 32,768 tokens smaller.
When other programs hold VRAM, the model starts with a smaller context instead of not at all.
Loads the model as soon as Qwen Station opens.

Coding agents

Qwen Station enters the model, its address and its context in the agents you switch on, now and at every start of the model. It only adds its own entry: everything else in their configs stays, and the first change keeps a backup next to the file. Switched off, an agent is no longer updated and keeps its entry.
